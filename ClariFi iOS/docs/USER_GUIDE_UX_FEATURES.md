# ClariFi User Guide - UX Features

## Overview

This guide covers the key user experience features in ClariFi that make managing your finances easier and more intuitive.

---

## Transaction Management

### Viewing Transactions

1. Tap the **Activity** tab at the bottom of the screen
2. Browse your transaction list
3. Tap any transaction to see full details

### Editing Transactions

You can edit any transaction to correct mistakes or add additional information.

#### How to Edit a Transaction

1. Open the transaction you want to edit
2. Tap the **Edit** button in the top-right corner
3. Modify any of the following fields:
   - **Date**: When the transaction occurred
   - **Merchant**: The name of the business or person
   - **Amount**: The transaction amount
   - **Category**: The spending category
   - **Notes**: Additional details or reminders

4. Tap **Save** to apply your changes
5. A success message will confirm your changes were saved

#### Validation Rules

ClariFi ensures your transaction data is accurate:

- **Merchant name** is required
- **Amount** must be greater than zero
- **Category** must be selected

If any field is invalid, you'll see a helpful error message and the Save button will be disabled until you fix the issue.

#### Canceling Changes

If you change your mind while editing:

1. Tap **Cancel** at the top-left
2. Your changes will be discarded
3. The transaction will remain unchanged

## Premium Features

### What's Included in Premium

Premium subscribers get access to advanced features:

- **Advanced Insights**: Detailed spending analytics
- **Custom Budget Categories**: Create personalized budget categories
- **Export Reports**: Download your financial data as PDF
- **Priority Support**: Get help faster when you need it

1. Navigate to any premium feature (like Planning)
2. Tap **Upgrade to Premium**

4. Complete the purchase through the App Store

If you're a premium subscriber:

1. Go to the Planning tab
2. Scroll to the bottom

4. This opens your App Store subscription settings

- Change your subscription plan
- Cancel your subscription

## Empty States

When you first start using ClariFi or haven't added content yet, you'll see helpful empty states that guide you:

### No Transactions

- **What you'll see**: A message explaining you haven't added transactions yet
- **What to do**: Tap "Add Transaction" to create your first transaction

### No Budget

- **What you'll see**: A message about setting up a budget
- **What to do**: Tap "Create Budget" to start tracking your spending goals

### Insufficient Data

- **What you'll see**: A message that you need more transactions for insights
- **What to do**: Add more transactions to see personalized analytics

## Feedback and Loading States

### Success Messages

When you complete an action successfully, you'll see a brief notification at the bottom of the screen:

- **Green checkmark**: Action completed successfully
- **Auto-dismisses**: Disappears after 2-3 seconds
- **Examples**: "Transaction saved", "Budget created"

### Loading Indicators

When ClariFi is processing your request:

- **Spinning indicator**: Shows work is in progress
- **Disabled buttons**: Prevents accidental duplicate actions
- **Progress messages**: Tells you what's happening

### Error Messages

If something goes wrong:

- **Clear error description**: Explains what happened
- **Retry option**: Try the action again
- **Cancel option**: Go back without making changes

## Troubleshooting

### Transaction Won't Save

**Problem**: Save button is disabled or shows an error

**Solutions**:
1. Check that merchant name is filled in
2. Ensure amount is greater than zero
3. Verify a category is selected
4. Check your internet connection

### Changes Not Appearing

**Problem**: Edited transaction doesn't show changes

**Solutions**:
1. Pull down to refresh the transaction list
2. Close and reopen the transaction detail
3. Restart the app if needed

### Premium Features Not Available

**Problem**: Still seeing upgrade prompts after subscribing

**Solutions**:
1. Restart the app
2. Check your subscription status in App Store
3. Ensure you're signed in with the correct Apple ID
4. Contact support if issue persists
